From any website

Right-click (or press and hold on a phone) the photo itself, then choose Copy image address (or Copy image link). Paste that into the box above. A link to the page the photo is on won't work — it has to point at the image file itself, and usually ends in .jpg, .png or similar.

From Google Photos

Open the photo so it fills the screen, right-click it and choose Open image in new tab. On the new tab, right-click the photo again and choose Copy image address — that link (it will contain googleusercontent.com) can be pasted above. The "Share > Create link" option gives a link to a shared album page instead, which won't display as a photo here.

From Google Drive

Right-click the file in Drive, choose Share, and set access to Anyone with the link. Copy the share link — it looks like https://drive.google.com/file/d/FILE_ID/view?usp=sharing. That link opens Drive's viewer, not the photo, so copy just the FILE_ID part (the long string of letters and numbers between /d/ and /view) and paste it into this address instead:

https://drive.google.com/thumbnail?id=FILE_ID&sz=w1000
